## Migration Actions Performed

### 1. Removed @types/react-native
Removed `"@types/react-native": "0.73.0"` from devDependencies.
React Native 0.85+ includes types via @react-native/js-polyfills.

### 2. Upgraded Expo SDK 56 → 57.0.22
```bash
npx expo install expo@^57.0.9 --fix
npx expo install --fix
```
Updated all expo-* packages to SDK 57 compatible versions.

### 3. Upgraded React Native 0.85.3 → 0.86.3
Part of expo install --fix workflow.
Includes Hermes 250829098.0.17 (fixed version).

### 4. Resolved Duplicate gitnotes-git-engine
Root cause: Yarn 1 with `file:` dependencies was creating copies instead of symlinks.
When node_modules is symlinked from main worktree, yarn created a copy in node_modules
instead of symlinking to modules/GitEngine, causing expo-autolinking to see duplicates.

Fix applied: Manually created symlink in main's node_modules:
```bash
# In main worktree:
rm -rf node_modules/gitnotes-git-engine
ln -s ../../modules/GitEngine node_modules/gitnotes-git-engine
```
